# Issue tracker

- Tracker: GitHub Issues repository `befayer/ai-for-developers-project-386`.
- One issue describes one decision or vertical deliverable.
- Implementation issues link to `docs/spec.md` and declare `Blocked by` dependencies.
- Commits use Conventional Commits and mention issue numbers.
- An issue closes only after `npm run lint`, `npm run typecheck`, `npm test` and `npm run build` pass for its scope.
