# Triage labels

Default labels used during issue breakdown:

- `kind:decision` — an unresolved product or architecture choice.
- `kind:feature` — a vertical product increment.
- `kind:quality` — tests, CI, delivery or maintainability.
- `area:contract`, `area:server`, `area:web`, `area:delivery`, `area:docs` — affected subsystem.
- `priority:high`, `priority:normal` — scheduling priority.
- `blocked` — cannot proceed until a declared dependency is completed.
