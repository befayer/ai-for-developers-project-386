# Спецификация приложения

## Цель

Сократить переписку при согласовании звонка: гость самостоятельно выбирает формат и свободное время, а организатор сразу видит новую встречу.

## Пользовательские истории

1. Как гость, я хочу увидеть типы встреч с описанием и длительностью, чтобы выбрать подходящий формат.
2. Как гость, я хочу увидеть свободные слоты ближайших 14 дней с шагом 30 минут, чтобы выбрать удобное время.
3. Как гость, я хочу оставить имя и email и получить подтверждение брони.
4. Как организатор, я хочу создать тип встречи и видеть встречи всех типов одним списком.
5. Как организатор, я хочу быть уверен, что два гостя не займут пересекающееся время.

## Решения

- Один преднастроенный организатор, гости без аккаунтов.
- Рабочее время MVP: будни 09:00–18:00 UTC; старт слота каждые 30 минут.
- Горизонт записи — не более 14 календарных дней, включая текущую дату.
- Время хранится в UTC ISO 8601; браузер отображает локальное время гостя.
- Длительности типов встреч: 30–120 минут, кратно 30.
- Конфликт определяется пересечением интервалов, а не совпадением идентификаторов типов.

## API и генерация

Контракт находится в `api/main.tsp`. Команда `npm run api:generate` создаёт:

- `docs/openapi/openapi.yaml`;
- `src/api/generated/` — типизированный SDK браузера;
- `server/generated/api-types.ts` — серверные типы.

## Проверка

- Интеграционный тест проходит полный сценарий API: тип → слот → бронь → список организатора.
- Отдельный тест отправляет повторную бронь того же времени через другой тип и ожидает HTTP 409.
- Smoke-тест проверяет `/api/v1/health` и наличие начальных типов встреч.
- CI запускает линтер, проверку типов, тесты и production-сборку на Node.js 22 и 24.
